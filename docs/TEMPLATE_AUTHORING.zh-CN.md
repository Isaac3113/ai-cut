# 把一段好效果做成自己的通用模板

本页属于 AI Cut 的「模板」路径，面向想保留、复用或分享效果的人。只想剪第一支视频，先看[自动剪辑教学](NOTION_GUIDE.zh-CN.md)；只想挑效果，打开[模板展厅](https://aicut.agi-top.com)或[逐项使用说明](../templates/README.zh-CN.md)。

## 先分清你要保留什么

- **成片 MP4**：已经输出的观看结果。
- **自用效果工程**：能在原项目、原素材上继续修改。
- **通用模板**：其他人可以按说明换内容，在明确支持的范围内重新制作。
- **`.motion` 包**：依 MotionGit 格式整理的可复用视频工程；是否能运行还取决于该包的引擎、依赖与输入。

MotionGit 平台用于发现与分享模板；[MotionGit Skill](https://github.com/adunext/motiongit-skill)用于从完成的工程提炼、打包模板。AI Cut 负责剪辑流程与效果选型，也可以按用户要求沉淀自制效果。三者各有职责，安装 AI Cut 不代表已经安装所有模板运行环境或官方打包工具。

## 第一步：先问效果来自哪里

把视频名称和时间告诉 AI。它应回查制作记录，区分：

| 结果 | 接下来怎样处理 |
| --- | --- |
| 套用现成模板 | 记录原作者、版本与实际修改，继续按该模板许可使用 |
| 自行实现 | 保留可编辑源码，开始提炼可替换参数 |
| 混合制作 | 分开列出第三方部分与自制部分，再决定可分享范围 |
| 只有 MP4、来源不明 | 先找原工程；无法恢复时说明需重新实现，不能把 MP4 改名当模板 |

“用了第三方动画引擎”和“套用别人现成的具体效果”也要分开说明。换字、换色或换人物后，原模板仍应保留来源。

```text
请核对这段效果的真实来源。
项目或成片：[填写名称或完整路径]
时间区间：[填写开始与结束时间]

请查源码、时间轴及模板记录，说明属于现成模板、自行实现还是混合制作。
列出来源、版本和实际改动；无法确认的地方明确告诉我，不从效果外观猜测。
本次先说明来源，不修改原工程。
```

## 第二步：让内容可以替换

例如一段三步流程图，原来固定写“吸引客户 → 预约 → 跟进”。通用化后，应能在支持范围内换成“报名 → 上课 → 作业”，并使用学员自己的颜色和标题。

| 要设计的输入 | 需要说明的范围 |
| --- | --- |
| 标题与正文 | 最长能放多少字，中文长句如何换行或分页 |
| 步骤或项目列表 | 支持几项，超过范围如何处理；不能为了模板编造步骤 |
| 颜色与字体 | 哪些能换，字体是否可分发，颜色对比是否可读 |
| 图片、Logo、人物视频 | 必需还是可选，支持什么格式，如何裁切及避开字幕 |
| 时长与节奏 | 固定时长还是按内容调整，如何与讲解/声音对齐 |
| 横版与竖版 | 哪些比例有实现并验证，哪些暂不支持 |

不用强迫每个模板支持所有参数。清楚说明“支持 3～5 步、横版、固定 8 秒”比宣称“什么都能换”更有用；这里的数字只是说明范围的例子，实际以该模板为准。

## 第三步：用不同内容证明它能复用

至少准备两组明显不同的输入，一组不依赖原作者的名字、品牌和素材。按声明范围检查长短文字、项目数量、配色、素材缺失、比例与时长，再实际生成并观看结果。有声音时也要听审，确认没有丢音或时间错位。

这样检查是为了发现“原作者电脑可以，别人一换内容就坏了”的问题。只看截图、原来的 Demo 或成功运行一次，不能证明所有新内容都适用。

## 第四步：整理说明和交付包

每个模板沿用[模板目录](../templates/README.zh-CN.md)的七项顺序：效果预览、适用内容、所需素材、可改参数与限制、怎样使用、当前可用与验证状态、来源和许可。

工程中还需要保留源码、参数定义、依赖要求、独立示例和许可。制作 `.motion` 时，让 AI 先核对[当前官方规范](https://motiongit.com/spec)与[官方 Skill 入口](https://github.com/adunext/motiongit-skill)，再依实际指南处理；不要把普通 ZIP 改扩展名冒充合格 `.motion` 包，也不要在模板里带上个人 Key、账号、私人路径或客户资料。

完成后，从最终交付包建立一个与原工程分开的实例，照教学替换内容并重新导出。源码已整理、`.motion` 已验收和另一台电脑实测，是不同状态，按实际结果分别说明。

```text
请把我指定的自制效果整理成可复用模板。
工程路径：[填写可编辑工程路径]
效果区间或组件：[填写]
希望开放的参数：[填写；不确定时先按真实实现提出建议]
希望支持的比例和输入范围：[填写]

先核对来源与许可，保留原工程、原片和已认可成片。
把内容与实现分开，移除个人路径和专属硬编码，写清输入及限制。
用至少两组不同内容验证，再检查声明范围的边界和实际导出画面/声音。
核对 MotionGit 当前规范及官方制作指南，将合适的工程打包为 .motion，并从最终包独立复验。
按七项固定顺序写使用说明，报告真实完成阶段、未支持项及输出位置。
本次先本机制作，不公开我的原片、人物素材、客户资料或凭据。需要付费服务先说明；公开哪些源码和示例由我另行明确。
```

## 第五步：决定哪些内容可以分享

可分享内容应有明确权利：自己的通用源码、可再分发的依赖、文档，以及已获授权或去个人化的示例。第三方模板、字体、音乐、Logo、肖像各有许可，代码开源不能代替这些授权。

AI Cut 所有者已经为自己指定的自制效果建立通用化与公开通用源码的长期要求；该要求不自动适用于下载仓库的学员。学员请明确自己的公开范围，尤其不要把包含私人凭据的个人 `.motion` 下载包直接放进 GitHub。

同步时维护同一份目录登记，生成 GitHub 与 HTML，检查教学入口；版本改变后说明支持范围和迁移方法。模板开发过程中保留原作品身份，避免一更新模板就改变已认可成片。

当前页是制作方法与检查标准，不代表现有全部 Demo 已转换为通用 `.motion` 包。执行规则见[效果溯源与模板创作](../skill/ai-cut/references/template-authoring.md)。
