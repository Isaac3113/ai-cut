

## 每条新视频怎样接入

1. 读取已验证库与最新成功的官方候选信息，按本片内容、画幅、语言和输入选型。
2. 已接入且适合就复用；尚未接入但适合、免费可得且许可允许，就沿授权直接取得本人原包，核验官方入口，检查真实输入并制作代表片段。
3. 技术通过后继续本片制作，把画面导入唯一主时间轴。记录稳定模板ID、官方来源、包版本、输入/依赖、调用方法、变体、真实Demo与QA；不虚填全片/用户认可状态。
4. 将必要的简短本人静音Demo和集成记录补入templates/template-integrations.json及限定Demo目录，重建中文清单、HTML中心和GitHub首页，只提交本次相关内容并保持Private。
5. 未开放、拿不到包、输入不符或技术失败时如实记录状态；付费采购和公开发布没有得到新增授权。仍继续其他可独立完成的工作。

完整执行规则以[模板长期接入](../skill/ai-cut/references/template-lifecycle.md)为准。只等新视频不是此前未全部接通的唯一原因；其余模板尚未逐包取得与验证，新片提供真实适用性和素材验证机会。
