# 国内剪映工程与窗口操作

用户指定剪映时使用本模式。继续复用主工程的转写、删改、字幕与 `timeline.compile_clips`；不重复识别，也不另建语义剪辑方案。原片、历史及已有成片保持不变。

## 工程准备

先核实本机软件版本、新草稿目录和可读取的真实空白模板。当前验证机器为Windows剪映专业版11.3.0.14362；其新建草稿的content/meta可能加密，嵌套timeline的template.tmp可能是明文。以实际文件为准，不套用国际CapCut或macOS的文件名。

上游 `jianying-editor` 的核心类负责构造轨道；本项目适配器负责统一时序、固定依赖与源文件哈希、字幕引用、三轨声音及结构检查。只允许全新输出目录。安装版本、生成文件和通过结构检查均不等于原生应用兼容通过。

原片分段按同一30fps输出边界排列。因帧长取整而需要的静音视频末端延伸须逐段记录，限制在一个输出帧内；人声保持现有编译后的原声轨，不通过延伸画面追加发言。背景音乐和SFX从0秒对齐，已应用轻音量的轨道不要再自动整平。

字幕与关键词为独立文本轨；颜色、描边和位置要在剪映与导出画面检查。现有B-roll、流程和头像可作为独立视频素材使用，但内部已经渲染的字形/动作不是原生可改元素，交付中应说明。

## 原生打开与导出

1. 在剪映创建本任务的唯一新草稿，保存并退出该工程编辑界面。
2. 备份这个新草稿。部署前重新核对被替换文件的哈希，保留原生登记资料，不修改其他草稿。
3. 用真实窗口工具打开候选，检查所有轨道、字幕、素材、人物构图和音量；遇损坏提示保留现场，定位原因后只作有依据的修正。
4. 由剪映界面导出本次比例的1080p/30fps/H.264/AAC MP4到全新路径；记录实际软件版本、设置、完成状态及导出文件哈希。
5. 对这个原生MP4完整解码并检查时长、音轨、帧、字幕、接缝与片尾。全片观看与实际试听分别记录；没有听到声音时不勾选通过。

不运行未经验证的上游UI导出器，不把快捷键触发或代理视频当完成。没有原生导出证据时继续标为候选工程。

## 同时使用电脑及手动修改

后台准备不占鼠标键盘。剪映窗口操作需要短暂使用本机焦点，检测用户输入或最小化导致无法观察时先恢复可观察状态；无法恢复则请用户将剪映置前台，继续其他后台工作。不要反复争夺鼠标键盘。

音乐、人声、SFX必须各有独立轨道。选中BGM片段后在剪映音频属性中调整音量；现有轻声WAV已带增益，100%是轻声基准。调整音乐不得同时降低人声，不把已有混合MP4当分轨工程。

若当前剪映显示百分比，把100%改为50%可将线性增益减半；若显示dB，把该轨0dB改为约-6dB。具体控件须看当前窗口，不凭版本猜位置。要完全去掉背景音乐时静音BGM轨即可，人声轨保持原值。

Codex右侧仅展示本次制作记录/预览，实际手动时间轴在剪映桌面窗口。手改后的原生工程保存新版本；不能直接覆盖主方案并假装两者已经自动双向同步。
