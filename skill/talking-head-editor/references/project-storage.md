# 独立项目与每条视频的目录

先确定用户指定的正式项目根目录；源码、知识库、动画源工程、可维护的总Skill源码均在此根内。不要把新的剪辑工程继续散放在聊天临时目录或 Downloads。

每条新口播在 `PROJECT_ROOT/视频项目/用户给定视频名/` 建一个独立文件夹。本用户命名形式为 `AIVD - 视频主题`；保留用户提供的完整中文名称，中文全角问号可以保留。Windows 不允许的字符先提出具体替代名，不默默改题。同一条视频的重剪、调速或换封面沿用原文件夹，仅新建版本。

```text
PROJECT_ROOT/
  skill/talking-head-editor/       总Skill源码
  scripts/ src/ extensions/       执行器与动画源工程
  03_Documentation/Knowledge_Base/
  视频项目/AIVD - 视频主题/
    00_视频说明.md
    01_原片/
    02_自有素材/
    03_参考视频/
    04_剪辑工程/                   主时间轴、转写、素材、Prompt和检查证据
    05_成片/YYYYMMDD_版本说明/     MP4、封面、TXT、SRT、完整制作说明
    06_历史交付/
  学员分发/                        脱敏分发源码和完整Skill包
  项目资料/                        用户规则原稿及迁移记录
```

实际建目录用 `python scripts/create_video_folder.py --name "AIVD - 视频主题"`；源码根为默认 PROJECT_ROOT，也可明确 `--root`。重剪加 `--existing`，不覆盖任何文件。原片复制或迁移后比对 SHA256；本机模式在04_剪辑工程内通过既有CLI创建或恢复job，不新增第二套时间轴。ChatCut模式同目录保存线上ID、最终快照与可恢复记录，云端素材不因本机移动而重新上传。

每次完整交付执行 final-delivery.md，并以本版哈希绑定所有文件。总目录或05_成片的“最新交付”入口需指向真实存在的一版。迁移前核对源码状态、已安装Skill、素材、运行时和全部路径；同盘搬移后核对文件清单、大小和关键哈希。历史证据保留原记录，并另写旧新路径映射，不篡改旧执行日志。兼容目录链接只作旧路径过渡，新任务使用正式根。

个人Codex Skill/官方插件仍安装在其应用管理目录中；项目保存可维护源码与安装绑定，不能搬走共享插件缓存冒充项目内容。更新安装时验证旧文件哈希，再绑定新源码根。迁移后实际运行依赖检查、相关回归、字幕导出及一个代表片段解码/导出，分开记录完整视听和未验证项。

Git只跟踪可分发代码与规则；视频项目、项目资料、学员包、原片、头像、模型、密钥和缓存必须忽略。保留用户明确指定的private可见性，不因目录或文件出现“public”字样就公开仓库。OneDrive目录存在不等于云同步已经完成。
