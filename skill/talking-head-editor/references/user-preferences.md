# 已认可的教学口播预设

2026-09-12 原创作者已认可最后的完整动画视频并要求以后完全沿用。当前标准为 **approved-vd44-teaching-v1**。后续同类视频直接使用，不重新要求确认同一种风格；用户的新要求优先。本页是该创作者预设，公开使用者可明确选用，并保留自己的身份、账号与素材授权。

## 内容与画幅

- 真人原声原意为主；删除无意义口癖、失败重录和冗余，保留有意强调、否定、条件和自然呼吸；重排按完整语义单元并保留修改理由。
- 默认跟原片显示比例只做一版，计入旋转/SAR；只有明确要求才做两版。已验证模板为1920×1080/30fps，9:16须重新排版和实片检查，不能直接拉伸或声称已经验证。
- 口播主体与原声音轨默认1.1倍一次，明确指定时按相对原声的绝对速度；2026-09-13本条改成1.2倍，后续默认未改。字幕和视觉事件共同映射到最终主时间轴，不能1.1×1.2叠加；外部动画/BGM保持1.0倍，封面与约3秒片尾单独计入，不再整体加速成片。

## 视觉与动画

- 默认 ChatCut 管理唯一主时间轴与导出；HyperFrames制作短状态卡、错落进场及HTML/GSAP动作；Remotion制作精确多步骤流转、计时、消息和头像片尾；普通重点字保留ChatCut原生可编辑层。
- 亮黄 #FFD545、奶油 #FFF3CB、墨黑 #20201E，红色少量用于否定/提醒。中文 Noto Sans SC；1080p基础字幕49px/700，重点短词110px/900、克制黑色偏移阴影。按构图调整，不能把这些像素值生搬到竖屏。
- 重点词分拍弹入、停留可读、及时退出。字幕和重点字分层，不把整段字幕做成巨字，不堆发光/仿3D。浅色流程保持明确字幕底区或深色实心字。
- 每3～5秒有有效可见变化，输出时间事件间隔上限5秒；人物轻推近/回位、短重点字、相关B-roll、对象动作均可。字幕换行、眨眼不算。不能为了达标让每一处都震动或响起音效。
- 场景先明确对象—动作—条件—结果。并列状态逐一呈现，不画成错误因果箭头；同一个客户卡的身份/状态连续。没有真实录屏时标“流程示意”，不伪装成交案例。
- 人物小窗只在帮助理解且不遮住状态、示意标识和字幕时使用，复制小窗显式静音。保留相关实拍和回到真人的节奏，不整条变成动画课件。

## 声音

- 人声、BGM、SFX分别可调；人声只播放一次。先使原声清楚，再加入音乐和音效；禁止混合后loudnorm把已压低的音乐重新放大。
- 选适合教学、无歌词、克制且许可明确的音乐。以已认可的极轻存在感为标准，保持自然速度、淡入淡出，停顿不突然变大。数字增益取决于原始文件与预处理，不复制本案例的人声+20.5dB给新原片。
- 本机历史安静基线：音乐预整平到-18LUFS，再施加music_gain_db=-35.020599913279625及已有侧链。ChatCut若导入的是已处理轻声文件，则0dB/100%是保持这个文件，不再次套相同衰减。选新曲目要重新测量与试听。
- SFX只在重点字/关键动作配轻短tap/pop/swipe。预整平后的线性5%（约-26.02dB）是上限起点，可更低；认可案例短点击实际为-40dB。5%不是相对人声响度，也不是电脑主音量。
- 音乐再减50%：只对所有BGM片段减6.0206dB/乘0.5；保留A1人声与A3音效。不要开启整轨自动响度，不能用降低真人声音来容纳效果。
- 每次检查最终音轨、人声清晰度、突发SFX与淡入淡出；信号分析与实际试听分别记录。没有实际试听不能记listened=true。

## 选材、片尾与交付

- 先质量、实际含义与用途，再比较自有/免费/付费素材；真实产品/客户/结果优先真实证据。许可明确的免费素材可按任务授权使用；付费须展示预览、价格与用途，经真实确认后购买。
- 片尾约3秒，原片真实本人头像、简洁结束语、黄黑分区；不伪造身份或新口播。学员使用自己的头像和品牌，不能继承案例人物。
- 每条完整短视频固定交付完整制作说明（逐段步骤、实际工具/素材/字幕/声音/效果及全片逐秒/逐帧对照）、TXT纯正文、最终SRT、独立封面、含封面的MP4，以及实际可见的工程和必要来源/删改/检查记录。按[固定交付](final-delivery.md)绑定同版证据，旧输出保留；缺证据/未试听不写已完成。
- 封面取本条真实原片好看的一帧，TXT交给[图片提示词员工](cover-prompt-worker.md)，主员工审核/优化Prompt后用内置imagegen生图，再实际嵌入视频。平台未给按原视频比例做一份通用封面，不捏造本人身份或文稿未讲的成果。
- 外部动画内部元素需改HTML/React再渲染，不能声称已全部成为原生可拆图层。
- 查看浏览器实际选中的时间轴，并定位关键动画；核对最终MP4同一位置。只有素材池里有动画不算合成完成。
- 风格已认可；全片连续视听、字幕人工同步等只能用真实证据更新。新原片继续检查，不自动发布、不自动买素材、不默认上传其他未授权文件。

完整顺序见[approved-workflow](approved-workflow.md)，所有质量细节见[master-playbook](master-playbook.md)。本页替代早期白色重点字、琥珀/青绿提案和“VD44待确认”的当前默认；历史工程仍保留。
