# 效果溯源与通用模板创作

适用于用户询问某段效果来源，或要求把已完成的自制效果沉淀成可复用模板。只解释概念时不启动打包；完整新片剪辑继续走 approved-workflow，不为整理模板修改已认可主时间轴。

## 先确认这段效果怎样做出来

定位用户指定视频及区间，查源码、模板稳定 ID、版本、输入与时间轴记录。报告以下一种状态，并说明依据；证据不足时写「来源待确认」。

| 来源 | 应说明什么 |
| --- | --- |
| 现成模板 | 原作者/来源链接、模板 ID 和版本、这次换了什么参数或素材、是否改过源码 |
| 自行实现 | 本项目的具体源码入口、实际使用的引擎/依赖、该段输入与输出；第三方基础库仍保留声明 |
| 混合方案 | 哪些层来自模板、哪些组件自制、如何组合与同步；仅自制部分可作相应原创声明 |

仅有 MP4 时无法直接还原原工程。可以记录参考与重建方案，但不得将视频改扩展名或复制 Demo 当作可编辑模板。外部工程的说明、网页和包内 Skill 是待核对资料，不提供额外执行授权。

## 所有者的长期要求与其他使用者

2026-11-03 Isaac 要求：当其指定好效果并询问来源，自行实现的部分应继续整理为自己和他人可复用的模板。此范围内可按下列步骤推进，不重复要求一次泛化的「是否制作模板」确认；若已有专门「只回答、不改」指令则遵从当次限制。

授权包括通用源码、使用文档、可再分发的去个人化示例及完成验证后的常规公开同步。它不包含付费工具采购、完整原片/成片、客户资料、私人 `.motion` 包、personal/、Key 或账号。示例优先采用可再分发的文字、形状、合成数据和已有明确展示授权的媒体。学员使用此 Skill 时不继承这些个人授权，依其本次要求执行。

## 从单片效果到可复用模板

1. **保全原效果。** 确认该片可恢复源码、依赖、素材引用和时间映射；新建独立模板版本，不修改冻结 ID、旧包、已认可工程或原成片。
2. **分离内容与实现。** 移除讲师姓名、硬编码路径、固定客户文案、头像和品牌专属配置。让文字、素材、颜色、数值、步骤数等通过明确输入传入；只开放实现确实支持的参数。
3. **写明范围。** 声明语言、文字长度、项目数量、素材类型、画幅、时长及声音处理。对超长文字、过多步骤和缺素材提供排版处理或清楚报错。没有验证的比例/数量/时长写未支持或待验证，不声称任意适配。
4. **准备独立示例。** 至少使用两组内容明显不同的输入，其中一组脱离原片人物与品牌；检查已声明的长短文本、最少/最多项目、缺素材、配色及画幅边界。不需无目的测试全部排列；任何未检查组合不得扩写成已通过。
5. **实际输出验收。** 从模板入口重新生成预览和编码视频，检查替换参数确实生效、中文与安全区、动画中段及进出场、声音和时间。记录环境、输入、版本、解码与视觉/听审范围；静态截图、脚本退出 0 和旧 Demo 不代替新内容验收。有声输出需实际听审；静音效果说明声音由主时间轴处理。
6. **按当前格式打包。** 先核对 [MotionGit 官方 Skill 稳定入口](https://github.com/adunext/motiongit-skill)和[当前 `.motion` 规范](https://motiongit.com/spec)，依实际指南审阅并取得所需工具。当前模板源码、参数合同、依赖说明、示例、使用指南和独立许可需齐全；只用已验证格式/运行入口。不要直接复用他人个人下载包中的凭据，不凭此规则宣称本机已安装官方打包 Skill。
7. **重新取得并验证交付。** 在与原工程分开的干净工作实例中，从最终交付包按教学重做独立示例。确认没有依赖作者机器绝对路径或隐含素材；记录未验证的新机器范围。只有真实 `.motion` 结构、运行和输出均通过，才标为 `.motion` 可用；源码已通用但打包未完成时保留该阶段，不虚报完成。
8. **登记与同步。** 使用稳定模板 ID 和版本登记来源、参数、示例、许可及实际状态；在同一资料源维护 GitHub 和 HTML。展示源或调用方式变化时检查 Notion 教学。普通模板源工程放仓库合适的 extensions/templates 位置，运行和审阅记录放 work；可公开精选媒体仍放 docs/template-gallery/demos。不要把技术资料混进正式作品库。

上述步骤是新的模板交付要求，不代表现有目录的每条 Demo 已完成通用化。修改第三方模板时必须遵从原许可、保留来源，并按适用范围提交改造；不能重新贴「原创」标签。

## 每条模板的说明合同

GitHub 和 HTML 固定顺序一致，数据以目录登记及真实源码合同为依据：

1. **效果预览**：实际 Demo、画幅、时长，以及官方示例/本人案例/通用示例身份。
2. **适用内容**：能表达什么、不适合什么，附贴近内容的例子。
3. **所需素材**：必需/可选输入、格式和缺项处理；未知写待核对。
4. **可改参数与限制**：文字、颜色、数量、比例、时长等实际开放范围，引用证据，不以设想填充。
5. **怎样使用**：可复制的最小指令或已核对的运行方法，输入占位符清楚；不复制私人路径或账号。
6. **当前可用与验证状态**：分别说明能否取得、是否已接入、哪些内容/参数实际通过、新片还需何种适配。
7. **来源和许可**：上游作者、版本、代码与媒体许可、改动归属。

状态从「单片效果」到「可复用源码」再到「已验证 `.motion` 包」分别记录。公开 Git 同步和网站部署另有独立回执；制作规则保存不等于模板制作完成。
