## 接手

每条新片先取得本条视频比例，再改变剪辑时间轴及动画、字幕布局。速度按本条创作者要求；只有明确选用原创作者预设时才将真人及原声源段绝对1.2倍一次，其他用户未要求加速则保持原速。既有工程不额外复乘；只提供“小红书”不算选择视频比例。

1. 先核对当前会话实际可调用的官方工具及当前账号，再读取本片 projectId、活动 timelineId 与浏览器实际选中的时间轴；没有证据的状态标未验证。旧电脑“已安装/已登录/已导出”记录只证明当时状态，不证明这台电脑当前可用。
2. 读原工程 revision、源片哈希、已有转写/删改记录，保留原片与历史版本。读取已保存的 ChatCut projectId；有工程就 target/read，不重复创建。每支成片只有一个权威主时间轴；长视频多切片可各建时间轴，每次读取、修改、预览或导出前显式核对目标projectId与timelineId，不依赖上次活动选择。
3. 官方 chatcut-plugin-basics 是接口入口；从当前工具 Schema 取字段，不把文档宣传当能力证据。插件安装、OAuth 成功、上传、时间轴修改、渲染、观看、试听分别记录。
4. create_project / get_editor_url 的 browserHandoff 用于右侧 Browser，完整保留内部参数；公开链接使用 editorUrl。不得保存 OAuth、上传令牌或临时登录链接进工程包/Git。

若当前没有可调用的 ChatCut 官方工具、账号未连接或工程不可读，说明具体缺口及其对在线手改/导出的影响；先完成原片检查、现有转写核对、事件设计和可独立完成的素材准备，并记录待导入项。不能静默用本地整片合成替代既定主路线，不能把 MP4、分轨 WAV 或可恢复 ZIP 说成已经建立的 ChatCut 工程。用户明确改选本机/剪映前，在线主工程保持待连接状态；不因缺工具重复索取已存在的任务授权。

## 可编辑时间轴

原片片段做主体，不导入旧的扁平成片冒充可编辑工程。按Script选择完整语义，再以本条实际绝对速度计算整数帧位置；已选作者预设为1.2，其他用户未要求加速为1.0。已有1.1倍改1.2倍时从源范围重算，不能叠乘成1.32。字幕／素材／动作都从这条时间轴取位置，封面占时同步计入。图层命名为人物、素材与流程、重点字、人声、背景音乐、重点音效。

历史 VD44 本机 r57 保留作参考，不覆盖它；该工程 ID/版本不作为新片工程。ChatCut 新剪完成后保存原工程哈希、当前官方快照及 Script；在线手改之后先重新读取，不用过期本地快照覆盖。原有工程恢复与原生修改自动回写并非已实现功能。

流程用真实对象/档案、动作和条件表现。并列状态不用因果箭头。声明“流程示意/情境示意”。配色、字重和动画按当前已提供参考；VD44提供分拍动作参考，本轮及以后颜色从实际Logo提取；按[品牌与圆窗](brand-and-presenter.md)建立独立水印、圆形真人层与核查证据。不把所有基础字幕改成大字。本人正文每个输出1秒区间都应有内容相关、可辨认的实际动画进展，连续动作可以跨秒，不要求每秒强切或响音效；须检查真实输出，抽帧不等于完整观看。提到Facebook、IG等平台时，按[平台图标随讲解出现](visual-storytelling.md#平台图标随讲解出现)配可取得的对应真实标识。复杂动作按[外部动画流程](reference-motion.md)导入，保留源码和帧绑定。

复制视频做画中画后，不能假设fromItemId复制了audioDetached；逐项inspect并显式muted:true，历史实测接口解析为-60dB（有效静音，非声称负无穷；当前接口重新核对）。保留A1唯一人声。历史工具说明列出layout-screen-face-bubble但当时返回Asset not found，不能声称预设可用；已用可编辑裁切框+圆角实现小窗，并对原片及合成帧比较人脸。全屏素材期间小窗是强制动态圆窗；遮挡“流程示意”、状态词或字幕时移动/缩放小窗或重排素材，不以移除小窗解决。必须实际验明圆形遮罩与源时码，旧圆角矩形的成功不证明圆窗已实现。

## 声音特别规则

detach_audio 后视频必须保持音频分离状态，原声只能播放一次。人声、BGM、SFX 三轨独立；重点音效按事件保留独立片段、名称、音源、起止时间与增益，使用户能在 ChatCut 点选单个音效替换/移动/删除/调音量。完整 SFX 混音可作校验或备份，不能代替承诺可逐个修改的主时间轴片段。已处理 BGM 导入后 0 dB / 100% 表示保持文件基准；只有用户要求再减半时，才对全部 BGM 片段减 6.0206 dB，不动人声。

不把旧 music_gain_db 再施加一次，也不启用整段自动响度去放大轻声音乐。角色 ducking 只有理解实际预处理链后才用；已有侧链处理的音乐不重复处理。SFX 以正常播放可听且不盖人声为准；历史5%、-38dB和-40dB只是旧素材记录，不是当前上限或新素材默认。实操区间按[practical-demo](practical-demo.md)围绕真实目标安排重点锚点，每个重点事件有对应同步轻音效；约3秒可作锚点节奏，但其间仍须满足正文逐秒动画进展，不要求每秒响音效。音量字段成功不等于听感合格。

历史 VD44 原声素材-38.5LUFS，原峰值约-19.3dBFS。早期以独立原声+17dB导出，测得-21.6LUFS/-4.7dBTP后仅把人声调到+20.5dB；音乐保持0dB，早期音效-38dB，最新VD44为-40dB。不能把+20.5写成所有原片的默认值：每条片须独立测量，不调低真人来容纳配乐。原声已从历史FFmpeg处理链换成ChatCut原生增益，不能宣称两版PCM相同或专业压缩器已实现。

## Windows 导入兼容

历史实测的官方 1.10.12 助手，其波形 ametadata 文件路径未转义 Windows 盘符。当时可用方式：在任务独立临时目录前台运行官方 helper，并仅为该进程设置 TMPDIR='.'；这样生成相对文件名，无须修改插件或系统变量。遇到已有占位 assetId 时按错误返回的 retry.args 和新 session 续传同一资源，不重复上传/注册。

本机无写权限/网络权限时走正式权限机制。若是明确拒绝上传文件，停止该上传路径，不换工具绕过。上传失败不转为本机重新扁平合成 ChatCut 主交付。

## 验证与交付

保存不含密钥的read_project／preview_timeline／read_captions／inspect_item证据，运行scripts/audit_chatcut_snapshot.py检查画幅、连续主视频、独立人声、支持的速度对应和字幕结构。始终显式传本条实际`--expected-speed`：原速为1.0，已选作者预设为1.2，其他明确速度用实际值，不能把脚本默认1.2套到学生视频。仅对与人声音轨配对的原片片段校验速度，无声封面／片尾只检查连续覆盖。结构检查不代替声音／画面质量。

用 ChatCut 实际导出的 MP4 做完整解码、响度/峰值/黑帧/冻结/静音候选检查。抽查全部接缝与流程动作。完整连续观看、试听、人工 200ms 同步未执行时显式 unverified，交付审阅版，不写“质量通过”。

按[成片交付](final-delivery.md)核对本条真实MP4、所需独立封面及已有对应字幕；选用作者预设时封面为16:9／9:16两张，附加营销文本仅按本条明确请求准备。在线工程链接在聊天中提供，TXT/SRT技术导出、制作说明与逐秒/逐帧对照、删改/素材/检查记录保留本机工作区。封面以真实资产入主时间轴，导出后实看首帧/边界；read_captions读取含封面与本条速度的全部卡片，再用scripts/export_final_subtitles.py导出同源TXT/SRT。实际建立的原生流程和重点字可编辑；Python/Pillow、HyperFrames、Remotion 制作的外部素材必须实际导入并放入这条时间轴。外部素材片段的起止、位置、缩放等仅按当前工具实测能力描述；其内部放大镜目标、文字或动作通常要回源码重渲染再替换，不能声称都已成为原生可拆图层。逐事件音效保持独立，不烘焙在无声特效素材里。XML/归档只在需要时导出并报告丢失效果等限制。

## 正确版本交付

既有浏览器可能保留旧Timeline选择，即使服务器activeTimelineId已是新版。导出后检查真实页面的活动时间轴名称/ID，定位关键动画，并对比实际MP4同一时刻。保留旧版但明确区分，不只给工程首页或单独动画。历史 VD44 完整版本已获原创作者风格认可；新片仍需独立检查。AIVD 4（旧001）的用户风格认可与本地成片不等于已建立 ChatCut 工程；截至2026-09-21的记录仍为本地工程，迁入与可编辑性必须有后续真实证据。


## 用户要求完整操作录屏时

在正式制作前启动真实屏幕录制，先验证可播放且确为当前工作画面，再进行导入、内容分析/选题执行、粗剪、字幕、包装、调音、预览、导出及交付核对。可按阶段分卷保留原始录屏并提供顺序索引。由Codex完成可执行操作；登录授权等必须由本人完成的步骤如实说明。

完整录屏保留真实等待、修改与检查，不用事后重演、日志、截图集或最终成片替代。记录各段起止和实际中断，缺录就标明缺口，不能仍称完整A到Z。此前未录制的环境准备独立披露；短录屏测试不是完整制作录屏。后台工具/代码运行与屏幕实际显示分开说明，不声称每个API动作都有鼠标操作。

先检查录制范围和系统播放声音能力；未录系统声要明确标注，不冒称有声教学录屏，不默认启用麦克风。录屏、母片及客户信息按任务授权保存，不因此获得对外发布权限。若工具连接尚未就绪，只做准备并如实报告；正式制作开始后才计算A到Z覆盖。
