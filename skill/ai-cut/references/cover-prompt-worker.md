# 图片提示词员工

这是 ai-cut 内部的封面提示词子任务，由当前 Codex 会话或其子代理执行；不需要把口播发给另一个未授权外部服务。主员工先提供最终正文 TXT、平台/显示比例、已实际查看的本人原片帧。生成后返回主员工审核，再由可用的内置 imagegen 生图。此文件的“只输出”约束只适用于子任务结构稿，不限制主员工交付真实进度和检查结果。

## 输入

本用户封面先读[user-preferences的当前视觉纠正与封面条目](user-preferences.md)。2026-10-26认可的`dark-frame-cutout-hook-v1`是可选风格之一：原片相关帧压暗作背景、真实本人完整可见轮廓描边、内容支持的hook及主副辅助字层级。参考图的Hub相对路径与哈希在该条目，采用时先实际看图。可按内容和画幅尝试其他风格，不把右下布局、具体斜黑体或固定标题锁为唯一模板；旧亮浅渐层加居中大头像及普通主题词不再作为默认。新图的审美认可仍按实际反馈记录。

### 基准先展示，10款分两张，确认才替换（2026-11-07优先）

选用作者预设时先执行[user-preferences的最新封面选择流程](user-preferences.md#封面先保留基准再给10个选择2026-11-07优先)：先单独展示当前基准，01保留该基准，另外9款为02—10；输出两张带编号对比图，第一张恰好01—05，第二张恰好06—10，并保留可打开的单张原图。新片基准沿用设计格式、使用本片实际标题及真实素材；同片明确保持时直接复用原图。

本子任务负责分别给新候选有区别的结构稿，不在一张生成图里拼出多个不可独立使用的小图。主员工逐张审阅真实生成结果后排对比图，记录真实来源；模板视觉参考不冒称已执行模板。默认候选采用本片已确认比例，选定后再独立排版正式16:9和9:16，不把10个选择误解为20张正式交付。

用户满意就保留基准；未批准替换前不改片内0.1秒封面、当前工程、视频导出或正式两张封面。下方“每片重新设计”指候选多样性与新片内容适配，不能覆盖用户明确保持原封面的指令。

### 每片重新设计，品牌保持连贯（2026-11-06）

用户随后明确认可AIVD-034第二版的16:9和9:16封面，要求以后保持这个质量标准。本次封面不再修改；后续继承hook清楚、真实人物突出、字形层级和流程关系易懂的质量，不照搬该片标题、构图或人物位置。认可范围以[user-preferences](user-preferences.md)记录为准。

- 每片重新考虑 **hook角度、整体构图、字形与信息层级、真实人物帧／姿态、画面组织**。复用品牌主辅色、身份、可读性和少量识别元素即可，不固定暗底、左文右人、右下描边头像或同一套字距／斜体。仅换标题、换色、镜像或轻移旧头像不算新设计。

## 职责与输出纪律

理解内容后只输出下面格式的最终封面结构。不要解释、分析、教学、原因、备注、建议、总结或额外开场。只选最值得做封面的一个重点，自动取舍其余信息，不为了完整堆字。标题至少给四个角度真正不同的版本；短、直观、有动作/结果/机制/冲突感，适合缩图，不用抽象黑话、课程标题或长句。

构图按内容选：左右人文分区、上下分层、中心焦点、对比双区或流程铺排都可以，不固定套同一模板。少而准的图标、聊天泡泡、客户卡、箭头、状态标签要有明确用途；不是每张都放四个元素，未需要的栏填“不使用”。并列状态不画成错误的先后因果，示意界面不伪装真实客户结果。

## 平台适配

| 平台 | 优先尺寸 | 设计重点 |
|---|---|---|
| YouTube | 1280×720，16:9 | 大标题、高对比、缩图可读、单一强焦点 |
| Facebook Feed | 1080×1080 或 1200×628 | 滑动中一眼看懂、结果直接 |
| Instagram Feed | 1080×1350 或 1080×1080 | 字少、视觉精炼 |
| Instagram Story / Reels Cover | 1080×1920，9:16 | 中间安全区、垂直层级、人物突出 |
| Facebook Story | 1080×1920，9:16 | 重点集中、中间安全区 |
| 小红书 | 1242×1660 或接近3:4 | 可读、生活/经验/方法感，不硬广 |
| 未指定平台 | 与本条视频显示比例一致 | 通用封面；不声称已验证特定平台UI安全区 |

平台只给大类时按该平台常见用途合理选择并填写结构稿。主员工保留用户明确比例优先级，不因员工推荐自动制作多个视频比例。

## 人物、文字与生成约束

本项目要求使用视频里的真实本人帧。保留本人脸部结构、发型、眼镜、衣着和可识别细节，不生成另一张相似脸。可去背景、调整布局与轻微光色，不改变身份。身份感可写“口播讲解者/专业亲切”，不能捏造职务、年龄、种族、国籍或获奖资历；用户未提供时相关字段填“沿用真实参考，不额外推断”。不得用模板对亚洲人、性别或年龄作无依据认定。表情与手势优先沿用原帧，不编造夸张动作。

标题最大，辅助文字仅补充，可不用；手机缩图下仍读得清。具体指定主色、字重、对比、留白和焦点。采用`dark-frame-cutout-hook-v1`时保留原片暗背景与真人轮廓；其他风格可按内容选择纯色、渐层、轻纹理或场景背景，不能抢字，也不机械恢复旧浅色大头像默认组合。只用实际口播支持的事实与结果，不添加虚构百分比、金额、获客数量、绝对承诺或随机英文。

避免赛博科技线条、神经网络风、复杂网格、密集UI截图、图标堆积、小字过多、低对比、模糊字、水印、装饰多于内容、同时讲多个重点、无意义摆拍和机械套版。主员工取得结构稿后必须核对本人、事实、中文、画幅、可读性及片内封面安排，形成审核后的执行描述；结构稿不直接跳过审核进入生图。
