# 文字B：逐字动态排版（无字幕底部横线）

历史可选的正文字幕风格；明确选择文字B或`legacy-knowledge-v1`时使用，不覆盖后来选定的其他风格。其他使用者按需选用，不继承讲师账号或媒体。它补充流程图解，不能代替讲解的对象、关系和步骤推进。

## 使用入口

- 源码：[kinetic-type-b.jsx](../assets/captions/kinetic-type-b.jsx)。
- 可编辑参数：[kinetic-type-b.properties.json](../assets/captions/kinetic-type-b.properties.json)。
- 许可：[LICENSE](../assets/captions/LICENSE)。字符波浪和遮罩机制参考本库 RenderComp WaveText / TextMaskReveal（Trimora Inc., MIT），已适配 ChatCut 字幕、实际帧率及文字布局。不是未经修改的官方 MotionGit 模板，也不是已封装的通用 .motion 包。

这是 **ChatCut Web caption_v1 字幕源**，通过当前 Web 的 edit_captions renderer 绑定真实字幕轨道；不要把它当普通 MG 上传，也不要把台词写死在源码。先读取当前字幕轨道、完整目标段及原生词时，再按当前工具合同提交 code 与 properties。Desktop 使用其独立模板合同，本文件未宣称 Desktop／独立 Remotion 工程可直接运行。

## 保留的文字玩法

逐字入场与轻微持续起伏、遮罩侧滑、拆分汇聚及短暂残影。所有文字由真实字幕协议提供；完整英文词保持可读，不能把 Agent 拆成 A / gent。持续运动不等于逐帧语义已人工验收。

**字幕下不画装饰横线、进度线或跟随播放增长的底线。** 不能用“提示进度”重新加回。流程图连接线、真实步骤引导线和必要关系标记按内容保留。

参数 treatment 提供 wave、mask、assemble 与 mixed。mixed 保留已认可样片的节奏参照（前7卡 wave、接7卡 mask、其后 assemble），不是自动理解新片内容。新视频先按实际语义段选择、适配三种玩法；不要把固定卡片序号或随机变换当语义判断，也不要因连续动画而破坏可读停留。

## 新片怎样适配

- 原声、文字、词时、剪切和语速先冻结；换样式不重新转写或重排原声。
- 保持字体、描边及品牌色的整体关系，按实际画幅调整字号和区域；源默认字号不是所有视频的强制像素值。
- 已有竖屏参考为1080×1920，字幕区域 left60/top1620/width960/height260。**这些只是该样片位置**；新片按实际人脸、手势和流程图留白重新检查，不原样套用横屏或不同人物。
- 检查长短句、英文词、最快入场和最大位移状态。字体衡量和绘制一致；超长单词或文字容不下时先调整分组／版式，不无限缩字或让文字跑出画面。
- 正文图解的标题／标签同样可逐字入场和持续运动；如复用既有图解，仅调整文字层，不修改已确认的对象关系和状态顺序。
- 换风格时保留原主版本并制作独立对照；仅获准试样就只导出指定范围，用户认可不是全片、文案、封面、云端归档或发布的合并授权。
- 0.1秒封面及固定片尾保持原合同，固定片尾不强加这套正文字幕或动效。

## 验证范围

已在原声真人竖屏样片中通过 Web 源码验证、字幕绑定及原生合成取样；本次无横线修改仅移除底线三处代码，其他运动保留。每条实际导出仍检查本版文件、字幕与运动边界；取样、解码和用户风格认可分别记录，不能补填完整连续观看／试听／口型检查。其他比例与宿主须单独实际验证，不能从竖屏样片推定。
