# 中文模板中心与按内容选择

## 正式入口与计数

收录范围面向所有行业：保留全部官方公开条目及原分类，不能只保留适合本项目所有者的模板。这里的“按内容选择”只针对本条制作，不是删减公共模板库。目录更新按[全库收录规则](template-lifecycle.md#官方全库收录与分类2026-11-03)执行；下列数量均为既有快照，不是永远固定的上限。

先按operations说明定位CODE_ROOT（环境变量、installation.json.source_root或当前源码目录），再读取该仓库的`templates/catalog.json`；用户阅读入口为`templates/README.zh-CN.md`，可播放目录为`docs/template-gallery/index.html`。不要假定模板数据跟着个人Skill目录被复制，也不要把讲师电脑绝对路径写入新片方案。

四个层级分别记录：官网集合72条（附74个官方Demo）、本期MotionGit包70控件（62场景＋8叠加、210变体）、现有Remotion55注册项（52基础实现＋3中文参数示例）、19个真人效果分支。不能相加后称为216套完整剪辑模板。官网集合不是全站总数；有Demo不等于已开放下载或已装好运行时。

用户于2026-10-27认可B版的官网局部效果。该认可支持按内容选用，不代表认可每套风格、70个控件、210个变体或整片自动套版。

2026-11-03展示要求：用户先按表达用途选型，四层来源与原分类继续作为标签和维护依据。所有条目按「效果预览、适用内容、所需素材、可改参数与限制、怎样使用、当前可用与验证状态、来源和许可」七项顺序展示；参数范围只来自真实合同或实现，不从演示推断。未知字段明确标待核对，官方参考/待开放不写成可直接运行。GitHub、HTML和教学共用登记资料；效果来源与通用化另读[模板创作](template-authoring.md)。

## 选择方法

先完成语义粗剪、保留原声与条件，并冻结最终帧和字幕。每条新片同时评估已接入与官方尚未接入候选；适合且免费可取得时，不重复询问接入许可，直接按[模板长期接入规则](template-lifecycle.md)核验、试做、接入并积累本人Demo。按本段要表达什么筛选目录：

| 表达任务 | 优先候选 | 使用条件 |
|---|---|---|
| 钩子、观点、重点句 | title、keyword、quote、highlight、kinetic | 原文支持，不把普通字幕全部做成大标题 |
| 概念、问答、限制 | definition、qa、tip、iconcards | 保留否定、条件，避免提前给出未成立的结论 |
| 顺序与系统关系 | steps、flow、timeline、mindmap、hub、cycle | 实际存在顺序／关系；并列不强画成因果 |
| 屏幕操作与证据 | 真实全屏画面、callout、spotlight、progressbar | 按钮、字样和鼠标目标清楚；窗口缩小影响阅读就保留原主画面 |
| 数据、价格、前后对比 | bars、donut、linechart、counter、price、beforeafter | 真实口径、单位、条件及对应素材；演示数据不可成为正式事实 |
| 品牌、CTA、装饰 | logo、cta、tag、lowerthird及少量装饰 | 符合原讲述；当前0.1秒封面与固定视频片尾不被模板intro/outro替换 |

无需每段加模板，不能为固定三项控件补造第三项。没有合适表达时，继续使用清楚的原画面和已验证基础效果。行业不是固定风格开关：AI主题不必总用科技风。

示例排行榜、模拟评论、星级、用户头像和虚构指标仅用于用户要求的教学／版式示例；在每个出现区间明确标注“示例数据”“示例评论，非真实用户评价”等身份，不作为该用户的成绩或真实客户反馈。

## 生产接入

ChatCut仍是本用户唯一主剪辑时间轴与最终导出入口；MotionGit／Remotion输出按需作为静音画面素材导回。保持声音、字幕与外部画面分开，不能把目录MP4演示当成本条完整成片，外部控件内部参数也不会自动成为ChatCut原生MG层。

MotionGit通过仓库`scripts/motiongit_adapter.py`调用原始个人包的官方入口。原包使用当前用户本人有权使用的版本；已授权的免费可得候选可由助手直接取得，需要用户登录或授权交互时才由用户完成。路径记录在被Git忽略的`motiongit.local.json`或用`--package`传入；不提取Key，不复制personal/或content/，不手拆保护代码。适配器只运行固定官方SHA已核的helper；未知版本先查官方元数据并审阅更新，不能重写期望哈希蒙混通过。

首次使用按实际包的公开guide/schema选择路线，核对setup/doctor；只读取所选控件合同，不默认加载整个库。本期包的句级字幕使用motion-kit，原生组需要真实逐词证据；不伪造units、不把native与kit任意混合。每个不同包重新确认能力，不能由相同.motion扩展名推断统一引擎。

正常执行为`new → contract/read → check-params/plan → prepare → preview → render`，原包动作以实际官方指南为准。先真实审阅计划和预览，再标记reviewed；每次新片或改参数另存输出。付费生成、素材采购与发布没有因模板接入得到新增授权。

## 时间、画面与声音

- 动画、字幕与音效共同使用最终剪后时钟；局部组件只减一次起点。已1.2倍的口播不再整体加速，外部动画按1.0倍插入。
- 完整句字幕不能用估算词时冒充逐字同步。Demo中的节拍和局部0秒计时不是正式整片的语音时钟。
- 模板字幕与主字幕只保留一份；不得重复叠原声、BGM或模板SFX。静音画面路线上只使用主时间轴已有声音，再按实际动作单独安排音效。
- 有同期本人源时保留真实同步人像。纯拍屏没有同期脸时不把界面的AI演员、旧片段或静态照片当讲师；保留真实画面并说明素材边界。
- 用真实Logo与品牌颜色，避开模板圆标／时码和字幕。模板保留的原生蓝色不自动等同品牌青色；新片需要重排并审看。

## Demo与验证状态

目录字段分别说明官方在线示例、本机源码渲染、本人素材演示、已实际导入与正式成片认可。全变体清单不等于全变体测试；静音组件不证明声音已协调；解码成功不证明连续观看或听审。

用户于2026-10-27追加长期授权：以后每条视频新接入或改进适配时，积累经过检查的精选本人Demo与来源、版本、调用合同和实际QA。2026-11-02用户另要求现有仓库公开；历史私人积累与公开上传分别判断，仅将已有明确公开授权且许可与隐私检查通过的小样同步仓库。允许的媒体路径仍仅docs/template-gallery/demos；完整原片、完整成片、源人像/遮罩、个人.motion、Key、账号、客户敏感信息和work缓存保持排除。细节见[模板长期接入规则](template-lifecycle.md)。

完整新片仍执行quality、品牌规则、固定片头片尾、用户精简交付与发布确认；模板演示不跳过这些阶段。
