# 编辑画布式知识口播

AI Cut的通用自制场景族。把真人、实拍素材、文档和流程放在同一画布里，用连续移动、展开与收束帮助理解。**视觉语言可以一致，场景选择和每支片的设计不必相同。**

## 1. 效果预览

预览入口由AI Cut统一模板目录登记；本目录的预设是去个人化示例，不含维护者本人原片或官方个人包。默认纸面示例20秒，另一组教育主题横版示例16秒；精选公开Demo是其中短节选，不代表原66秒视频全部已打包。

## 2. 适用内容

适合知识讲解、方法拆解、并列岗位、输入与输出、步骤推进和结尾收束。先判断语义，再用`hook / prompt / shift / flow / gallery / folder / closing`组合。没有顺序关系的内容不要硬画成流程；纯旅游Vlog、多机剧情和精细人像抠像不是本模板能力。

## 3. 所需素材

- 必需：新片的标题、短句、场景选择和真实时长。
- 可选：本条同期人物视频、说明图片／实拍视频、已有字幕的真实时间。
- 中文渲染需可用中文字体，建议用有权使用的Noto Sans SC字体文件，通过`font`绑定；未随包附送字体。当前只验证Windows和明确绑定的本机字体，未验证其它电脑的字体回退。
- 媒体与字体不随作者包附送。`--assets`目录由用户提供，JSON中只用相对路径。缺少媒体时显示中性的内容窗口示意，不伪造人物或实际软件截图。
- 素材原音不会混入输出；原声、配乐和音效在唯一主剪辑时间轴合成。

## 4. 可改参数与限制

| 输入 | 已实现范围 |
|---|---|
| 场景 | 1–12段；每段3–12秒，总长≤120秒；可改顺序或重复 |
| 文字 | 标题≤26字、重点≤20字、说明≤70字；长文应自行拆镜，不以缩小成蚂蚁字代替 |
| 项目数 | 流程2–5项；4／5项流程至少4／5秒，避免后面步骤尚未入场就结束。其他1–3项。hook短标签≤6字，其他项目标题≤12字 |
| 说明 | 流程项目≤20字，其他项目≤32字；超范围在渲染前拒绝 |
| 布局与色彩 | `paper-editorial`、`dark-workbench`、`material-wall`；主色、辅色、纸面、墨色可变。变体控制统一视觉语言，场景与素材仍随内容重新选择 |
| 画幅 | 9:16与16:9分别布局，30fps；并非把竖版拉伸成横版 |
| 人物／素材 | `image`或`video`，素材视频支持`sourceStart`；人物按全片时钟，使用`presenterStart`；素材窗口按各场景局部时钟 |
| 字幕 | 已有真实起止时间，按短句显示；竖版每条≤24字，横版≤45字；不自动生成ASR或伪造词时 |
| 声音 | 本适配器始终输出静音；原声和音乐交给主剪辑，不自动TTS或付费 |

`seed`用于确定轻微构图运动，不是无意义随机炫技；不要只改seed就当完成新设计。画面中的窗口、文件和步骤都是可修改的设计内容，不会操作真实软件。

## 5. 怎样使用

先安装Node.js 22+、Chrome／Chromium，以及本机可用的FFmpeg环境；在解包目录安装此`package.json`中的固定依赖。不要把`node_modules`放入Git或重新打包。

```sh
npm install
node render.mjs --input presets/demo.json --assets YOUR_ASSETS --out NEW_INSTANCE --chrome YOUR_CHROME_PATH
```

复制预设后改内容，`duration`须等于各场景秒数之和，由助手按实际时钟计算；需要中文时给输入加上`font`，对应字体放到`YOUR_ASSETS`里。人物绑定示例：

```json
{
  "presenter": "presenter.mp4",
  "presenterType": "video",
  "presenterStart": 0,
  "presenterLabel": "你的显示名",
  "font": "font.ttf"
}
```

这些字段合并进完整预设，不是独立完整输入。新计划先做代表帧，再完整渲染：

```sh
node render.mjs --input MY_INPUT.json --assets YOUR_ASSETS --out NEW_PREVIEW --chrome YOUR_CHROME_PATH --mode still --time 6
node render.mjs --input MY_INPUT.json --assets YOUR_ASSETS --out NEW_RENDER --chrome YOUR_CHROME_PATH
```

输出目录必须不存在，避免覆盖旧版本。输出`video-silent.mp4`以1.0倍嵌入已冻结主剪辑；不要再次给它乘上整片口播的旧速度。

## 6. 当前可用与验证状态

源码和适配器可在声明依赖齐全时直接运行。真实验证结果由`validation-summary.json`和统一目录说明，不把“代码存在”“包检查通过”和“真实导出通过”混为一项。`.motion`是无凭据的作者内容包，使用自声明`ai-cut.remotion/1`适配器；不冒称MotionGit网站个人下载签发包或平台已审核作品。

公开作者包不含个人Key、帐号、原片或完整成片。解包后按本适配器运行；目前没有宣称其它宿主自动识别该自定义profile、官网个人包消费流程或另一台电脑已实测。

## 7. 来源和许可

通用组件由AI Cut从自己实现的编辑画布、窗口、展陈及资料收束方法适配，MIT；Remotion/React按各自许可使用。视觉方向参考公开知识口播常见的编辑画布语言，未复制博主视频、音乐或素材。

原66秒示例中的MotionGit现代图文alpha.4官方原生场景属于独立第三方模板，不在此自制源码包里，也不标原创。HyperFrames段原用Apache-2.0官方流程构造适配，亦不以私有原包形式复制进本包；这里的流程组件是新写的通用Remotion实现。

依赖、字体、实拍素材、人物肖像与声音授权分开核对。这个源码许可不会授权公开他人的素材，也不会继承维护者的云盘、发布系统或付费账户。
