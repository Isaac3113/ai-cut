# AI Cut Editorial Canvas

For an AI assistant: inspect `motion.json`, `guide.json`, `SKILL.md` and `params.schema.json` before running code. Use this package's `ai-cut.remotion/1` adapter according to [the Chinese production guide](README.zh-CN.md). This is an author content package, not a signed website personal-download package.

The package contains a configurable family of original/adapted editorial motion scenes, not the original 66-second private film. Supply your own text, media, Chinese font and parent speech timeline. It does not include owner accounts, private footage, API credentials, or the third-party MotionGit native scene.

Node.js 22+, the pinned package dependencies and Chrome/Chromium are required. `render.mjs` produces a silent visual; do not discard or retime the original voice to fit it. Template source is MIT; dependencies and supplied media retain their own licenses.
